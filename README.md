# Sagar Shiriskar — website

Personal site for [sagarshiriskar.com](https://www.sagarshiriskar.com). Built with [Jekyll](https://jekyllrb.com/) and edited through [Pages CMS](https://pagescms.org/).

## Editing content

Use **Pages CMS** (connected to this GitHub repo) to update:

- **Works** — each project in the collection
- **Order of works** — homepage order (drag and drop)
- **About** — images and text on the about page
- **Site settings** — navigation, footer, SEO title and description

After you save, the site rebuilds on Netlify. You do not need to run anything on GitHub.

**Works order and new projects:** see [documentation/works-order.md](documentation/works-order.md) (setup, what runs automatically when you save, troubleshooting).

**Image and video file names:** see [documentation/asset-file-naming.md](documentation/asset-file-naming.md).

## Preview on your computer (optional)

```bash
bundle install
bundle exec jekyll serve
```

Open [http://localhost:4000](http://localhost:4000). Restart the command if you change `_config.yml`.
